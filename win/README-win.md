# 视频时长/大小自动整理分类脚本说明

该脚本用于自动扫描指定目录下的视频文件，并根据视频时长和文件大小，自动将其归类整理到 3 个目标文件夹中。

## 目录结构

扫描之后，会在指定的**目标路径**（默认为扫描路径本身）生成以下三个文件夹：
1. **`1_Clips` (短视频/片段)**：默认时长小于 2 分钟（120秒）的视频。
2. **`2_Records` (常规视频/记录)**：默认时长介于 2 分钟到 15 分钟之间，且大小小于 500 MiB 的视频。
3. **`3_Archives` (长视频/归档)**：默认时长大于或等于 15 分钟（900秒），或者文件大小大于或等于 500 MiB 的视频。

---

## 依赖要求

1. **Python 3.x**
2. **ffmpeg**：
   - 脚本需要使用 `ffmpeg` 来解析视频的时长。
   - 请确保系统已安装 `ffmpeg` 并已加入系统的环境变量（PATH）中。
   - 如果未加入环境变量，也可在运行脚本时通过 `--ffmpeg` 参数手动指定 `ffmpeg` 可执行文件的绝对路径。

---

## 使用方法

### 1. 模拟运行 (Dry-Run / 默认安全模式)
默认情况下，运行脚本只进行扫描和分类预览，**不会对文件做任何物理移动或修改**。
它会在目标路径生成一份 `_sort_plan.csv` 的清单，供您预览和核对。

```bash
# 扫描当前目录或指定目录，并把结果生成在指定目录
python sort_by_duration.py "D:\your\video_folder"
```

### 2. 实际执行移动 (`--execute`)
当您通过模拟运行确认生成的 CSV 清单无误后，添加 `--execute` 参数来真正执行文件的移动分类。
执行后会在目标路径生成 `_sort_executed.csv` 记录实际移动的结果。

```bash
python sort_by_duration.py "D:\your\video_folder" --execute
```

### 3. 指定不同的输出目录并提取所有视频 (`--dest` & `--flatten`)
如果您希望将源目录下的所有视频提取出来，并直接移动到另一个独立的文件夹的分类目录中（扁平化存放，不保留源目录的多级子目录结构），可以使用 `--dest` 参数指定目标输出路径，并加上 `--flatten` 参数。

```bash
# 将 D:\source_videos 下所有子目录中的视频提取出来，扁平化移动到 E:\sorted_videos 下的三个分类文件夹中
python sort_by_duration.py "D:\source_videos" --dest "E:\sorted_videos" --flatten --execute
```

## 高级自定义参数

您可以通过命令行参数灵活修改分类标准和运行配置：

| 参数 | 说明 | 默认值 | 示例 |
| :--- | :--- | :--- | :--- |
| `scan_dir` | **(必填)** 要扫描的视频源目录 | - | `D:\videos` |
| `--dest` | 整理后的文件夹输出基准路径 | 与 `scan_dir` 相同 | `--dest E:\sorted` |
| `--execute` | 真正执行移动操作。如果不加此参数，则只进行模拟运行 | 否 | `--execute` |
| `--flatten` | 扁平化存放。开启后所有视频将直接存放在分类文件夹下，不保留源目录的多级子目录结构 | 否 (保留子目录结构) | `--flatten` |
| `--ffmpeg` | `ffmpeg` 可执行文件的路径 | `ffmpeg` | `--ffmpeg "C:\tools\ffmpeg.exe"` |
| `--workers` | 并发探测视频时长的线程数 | `6` | `--workers 10` |
| `--clips-dur` | 归类为 `1_Clips` 的最大时长限制 (秒) | `120.0` (2分钟) | `--clips-dur 60` (1分钟) |
| `--arch-dur` | 归类为 `3_Archives` 的最小时长限制 (秒) | `900.0` (15分钟) | `--arch-dur 1800` (30分钟) |
| `--arch-size` | 归类为 `3_Archives` 的最小文件大小限制 (MiB) | `500.0` | `--arch-size 1024` (1GB) |

### 示例：
使用 8 线程并发，将时长小于 1 分钟的归为 clips，大于 30 分钟或大于 1GB 的归为 archives，实际执行：
```bash
python sort_by_duration.py "D:\videos" --clips-dur 60 --arch-dur 1800 --arch-size 1024 --workers 8 --execute
```

## 特殊保护机制

为了防止误操作，脚本内置了以下智能过滤规则：
1. **实况照片 (Live Photos) 过滤**：如果视频文件的同级目录下存在同名的图片文件（如 `IMG_0001.MOV` 与 `IMG_0001.JPG`），且视频长度小于 6 秒，脚本会判定其为实况照片的动态部分，并**自动跳过**，不予移动，防止破坏 Live Photo 的关联。
2. **未知格式过滤**：如果因视频损坏或格式不支持导致无法探测到时长，且文件大小小于 500 MiB，脚本会**自动跳过**。
3. **同名防覆盖机制**：如果移动目标路径已存在同名文件，脚本会自动重命名为 `文件名 (1).mp4`、`文件名 (2).mp4` 等，绝对不会覆盖已有文件。
4. **防循环扫描**：如果输出目录在扫描目录内部（即默认情况），脚本在递归扫描时会**自动跳过**已生成的 `1_Clips`、`2_Records` 和 `3_Archives` 目录，防止重复扫描和无限循环。
